# RACKET Wave

Use this skill to create or update RACKET waves.

## Wave requirements

- Define the COURT contract consumed by the engine.
- Identify affected crates and renderer/runtime backends.
- Break the wave into small pulses.
- Include validation expectations for every pulse.
- Record non-goals.
