# RACKET Invariants

## RACKET-INV-01: Frame Plans Preserve COURT Intent Without Rules

**Status:** MITIGATED

**Claim:** Frame plans preserve COURT snapshot scene/action intent without
adding product rules to `racket-core`.

**Why it matters:** The adapter proof is valid only if it maps intent rather
than deciding gameplay.

**Enforcement:** Unit tests exercise frame-plan conversion over COURT snapshots.

**Evidence:** `crates/racket-core/src/lib.rs` and
`cargo test frame_plan_consumes_court_snapshot_without_rules`.

## RACKET-INV-02: Runtime Loop Is Deterministic And Windowless

**Status:** MITIGATED

**Claim:** The foundation runtime loop steps frame plans deterministically
without opening a window or selecting a renderer.

**Why it matters:** Renderer/backend expansion must be based on reproducible
adapter evidence, not visual side effects.

**Enforcement:** Runtime-loop tests compare deterministic frame behavior.

**Evidence:** `crates/racket-core/src/lib.rs` and
`cargo test runtime_loop_is_deterministic_and_windowless`.

## RACKET-INV-03: Proof Surface Covers Ready And Not-Ready Reports

**Status:** MITIGATED

**Claim:** The retained proof fixture records one ready report and one
structured not-ready report with an `action-unavailable` diagnostic.

**Why it matters:** RACKET needs both success and explicit unsupported-path
evidence before product repos can trust adapter diagnostics.

**Enforcement:** Integration tests compare generated proof reports against the
retained fixture.

**Evidence:** `crates/racket-core/tests/proof_surface.rs`,
`crates/racket-core/tests/fixtures/runtime-proof.json`, and
`cargo test --test proof_surface`.

## RACKET-INV-04: RUNE Descriptor Fixture Matches Runtime Metadata

**Status:** MITIGATED

**Claim:** `docs/rune/adapter_contracts.json` matches the descriptor collection
generated by `racket-core`.

**Why it matters:** Agent-facing metadata must not drift from the adapter
contracts it describes.

**Enforcement:** RUNE descriptor tests compare collection identity and retained
fixture bytes.

**Evidence:** `docs/rune/adapter_contracts.json`, `docs/rune/README.md`, and
`cargo test rune_contract_registry_preserves_adapter_metadata`.

## RACKET-INV-05: VTRACE Role Summaries Cite Current Local Roles

**Status:** MITIGATED

**Claim:** VTRACE role-review summaries cite the current `.roles/ROLE.md` panel
instead of stale "no roles" language.

**Why it matters:** Role review is part of RACKET's gate; stale role-presence
text misleads later agents about available review lenses.

**Enforcement:** PITFALL adoption updated VTRACE role summaries and
`git diff --check` verifies the documentation change.

**Evidence:** `.roles/ROLE.md`, `docs/vtrace/MISSION.md`,
`docs/vtrace/TRACE.md`, and `git diff --check`.
