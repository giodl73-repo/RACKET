How text and originals are kept

Opened UTF-8 bytes, including BOM and CRLF, remain available as the original download. The editor displays line endings as LF. Inspection and current-text download keep the loaded text until you edit it. Editing uses the editor's LF text. An explicit LF copy removes a leading BOM and normalizes CRLF/CR; the original download stays intact.
